What is Open Graph Protocol?

Open Graph (OG) is a protocol created by Facebook in 2010 that turns web pages into rich objects in a social graph. When you share a URL on Facebook, LinkedIn, Discord, WhatsApp, or Slack, these platforms read the OG meta tags in your HTML to generate a rich preview card — showing an image, title, and description instead of a plain URL.

The protocol uses <meta property="og:..." content="..."> tags in the <head> section of your page. Without them, platforms will attempt to guess a title and description from your page content — often with poor results.

Required Open Graph Tags

The Open Graph protocol specifies four required tags for every page:

  • og:title — The title of your content. This becomes the headline of the share preview card. Keep it concise (60-90 characters).
  • og:type — The type of object (e.g., website, article, product). This tells platforms how to categorise your content.
  • og:image — An image URL for the preview card. Recommended size: 1200 × 630 px (1.91:1 ratio). This single tag has the biggest impact on click-through rates.
  • og:url — The canonical URL of the page. This ensures all shares point to the same URL, consolidating engagement metrics.

Additionally, og:description and og:site_name are strongly recommended for optimal previews across all platforms.

Twitter Card vs Open Graph

Twitter has its own meta tag system called Twitter Cards (twitter:card, twitter:title, twitter:description, twitter:image). When both Open Graph and Twitter Card tags are present, Twitter will use its own tags. If Twitter-specific tags are missing, it falls back to Open Graph.

The main difference is the twitter:card tag, which has no OG equivalent. It controls the card layout: summary (small square image left-aligned) or summary_large_image (wide banner image above the text). Most websites should use summary_large_image for maximum visual impact.

Frequently Asked Questions

What is Open Graph?

Open Graph is a protocol by Facebook that lets you control how your pages appear when shared on social media. It uses meta tags (og:title, og:description, og:image, og:url) to define the preview card shown on Facebook, LinkedIn, Discord, WhatsApp, and other platforms.

What is the ideal OG image size?

The recommended size is 1200 × 630 pixels with a 1.91:1 aspect ratio. This works well across all major platforms. Use JPEG or PNG format and keep the file size under 5MB. Facebook requires a minimum of 200 × 200 px, but larger images produce better preview cards.

Do Twitter Cards override Open Graph tags?

Yes. When both are present, Twitter uses its own tags (twitter:title, twitter:description, twitter:image). If only Open Graph tags are set, Twitter falls back to those. The twitter:card tag (summary or summary_large_image) has no OG equivalent and must always be specified explicitly.

Why is my OG preview not updating after I changed the tags?

Social platforms cache OG data aggressively. Use Facebook's Sharing Debugger to scrape fresh data. For Twitter, use the Card Validator. LinkedIn has an Post Inspector tool. You may need to wait a few minutes for caches to clear.

Can I use different images for Facebook and Twitter?

Yes. Set og:image for Facebook/LinkedIn/Discord and twitter:image for Twitter. Twitter will prefer its own tag. This is useful because Twitter's summary card works best with a 1:1 square image, while Facebook prefers 1.91:1 landscape.
