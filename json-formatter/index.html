What is JSON?

JSON (JavaScript Object Notation) is a lightweight, text-based data interchange format. It was originally derived from JavaScript, but today it is language-independent and used by virtually every modern programming language — from Python and Java to Go and Rust.

JSON is the de facto standard for APIs, configuration files, and data storage. Its simplicity and readability make it ideal for transmitting structured data between a server and a web application, or between microservices in a distributed system.

Formatting (or "beautifying") JSON means adding consistent indentation and line breaks so that the data is easy to read and debug. Minifying does the opposite — it strips all unnecessary whitespace to reduce file size for production use.

  "name": "DevToolsHub",
  "version": 2,
  "features": ["JSON Formatter", "CSV Converter", "UUID Generator"],
  "isOpenSource": true,
  "pricing": null

Common JSON Errors

If your JSON fails validation, check for these common mistakes:

  • Missing quotes around keys — JSON requires all keys to be double-quoted strings. {name: "value"} is not valid; use {"name": "value"}.
  • Trailing commas — A comma after the last item in an array or object is not allowed. {"a": 1, "b": 2,} will fail.
  • Single quotes instead of double quotes — JSON only accepts double quotes ("). Single quotes (') are not valid.
  • Missing closing brackets — Every { needs a }, and every [ needs a ]. Mismatched brackets are a frequent source of errors.
  • Using undefined, NaN, or Infinity — These JavaScript values are not part of the JSON specification. Use null for missing values.

JSON Formatting Options

This tool supports three indentation styles. The right choice depends on your project and team conventions:

  • 2 spaces — The most common choice for web projects. Preferred by JavaScript, TypeScript, and Node.js communities. Compact but readable.
  • 4 spaces — Popular in Python, Java, and C# ecosystems. Provides more visual separation for deeply nested structures.
  • Tab — Allows each developer to set their preferred visual width in their editor. Some teams prefer tabs for accessibility reasons, as users can adjust the display width.

The "Sort keys" option alphabetically orders all object keys at every level. This is useful for creating consistent diffs in version control, or when comparing two JSON objects to quickly spot differences.

Frequently Asked Questions

Is my data safe?

Yes, completely. This tool runs 100% in your browser using JavaScript. Your JSON is never sent to any server, stored in any database, or logged anywhere. You can verify this by checking the Network tab in your browser's developer tools — no outbound requests are made when you format or validate.

What's the maximum JSON size this tool can handle?

There is no hard limit imposed by the tool itself. In practice, it comfortably handles JSON files up to 10 MB. For very large files (50 MB+), performance depends on your device's available memory and browser. If you experience slowness, try using the minified format or splitting the data into smaller chunks.

Can I format JSON with comments?

Standard JSON (RFC 8259) does not support comments of any kind — neither // single-line nor /* */ multi-line comments. If your data contains comments, you need to remove them before formatting. Formats like JSONC (used in VS Code settings) and JSON5 do allow comments, but they are supersets of JSON — not valid JSON.

What is the difference between JSON.parse() and JSON.stringify()?

JSON.parse() takes a JSON string and converts it into a JavaScript object. JSON.stringify() takes a JavaScript object and serializes it into a JSON string. This tool uses both: it parses your input to validate it, then stringifies it with the desired indentation to produce the formatted output.

Does this tool support JSON5 or JSONC?

No. This tool validates and formats standard JSON only (RFC 8259). JSON5 and JSONC are supersets that allow features like comments, trailing commas, and unquoted keys — none of which are valid in standard JSON. If you need JSON5 support, consider using a dedicated JSON5 parser.
