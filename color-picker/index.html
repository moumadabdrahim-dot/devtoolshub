Understanding Color Models

Different color models serve different purposes. HEX is the standard for web CSS, RGB models how screens emit light, HSL is intuitive for designers adjusting hue/saturation/lightness, and CMYK is used for print output.

WCAG Contrast Guidelines

The Web Content Accessibility Guidelines (WCAG) define minimum contrast ratios for readable text:

  • AA Normal text — 4.5:1 minimum contrast ratio
  • AA Large text (18px+ or 14px+ bold) — 3:1 minimum
  • AAA Normal text — 7:1 minimum (enhanced)
  • AAA Large text — 4.5:1 minimum (enhanced)

Always test your color combinations against WCAG standards to ensure accessibility for users with visual impairments.

Frequently Asked Questions

What is the difference between RGB and HSL?

RGB defines colors by mixing Red, Green, and Blue light intensity (0-255 each). It mirrors how screens physically work. HSL defines colors by Hue (color wheel angle, 0-360°), Saturation (intensity, 0-100%), and Lightness (brightness, 0-100%), which is far more intuitive for humans adjusting colors visually.

When should I use CMYK values?

CMYK (Cyan, Magenta, Yellow, Key/Black) is the standard for print production. If you are designing for web only, use HEX or RGB. If your design will be printed (brochures, business cards, packaging), use CMYK values as your reference since printers use this color model. Note that CMYK has a narrower gamut than RGB — some vibrant screen colors cannot be reproduced in print.

What is WCAG contrast ratio?

The WCAG contrast ratio measures relative luminance between two colors on a scale of 1:1 (no contrast) to 21:1 (black on white). It is computed using a formula that accounts for human perception of brightness. Meeting AA (4.5:1) or AAA (7:1) ensures text is readable by users with moderate to severe visual impairments.

How do complementary colors work?

Complementary colors are 180° apart on the HSL color wheel. They create maximum visual contrast and make each other appear more vivid. Examples: blue ↔ orange, red ↔ cyan, purple ↔ yellow. Analogous colors (30° apart) create harmonious combinations, while triadic colors (120° apart) create balanced, vibrant palettes.
